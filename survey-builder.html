처음 한 번만: 응답 시트 연결하기
  1. 응답을 모을 구글 스프레드시트를 새로 만듭니다. (sheets.new)
  2. 시트 메뉴 확장 프로그램 → Apps Script를 열고, 기존 코드를 지운 뒤 아래 코드를 붙여 넣고 저장합니다.
  3. 배포 → 새 배포 → 웹 앱을 고르고 실행: 나, 액세스: 모든 사용자로 배포합니다. 권한 승인 창이 뜨면 허용합니다.
  4. 나온 웹 앱 URL을 위의 ‘응답 수집 주소’ 칸에 붙여 넣습니다.
  5. 홈페이지 저장소(sabsci-lab)에 survey.html을 한 번 올립니다. 그러면 설문 링크가 sabsci-lab.com/survey로 열립니다.
